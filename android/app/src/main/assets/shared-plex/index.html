Harmonicast · Shared access setup

Prepare your Plex library

Download the setup ZIP onto this computer, then extract it onto your server or network share. The audio tags are already filled in. No shell script or MusicGrabber changes are needed.

Download setup ZIP

Keep the setup screen open in Harmonicast. This local page is available for five minutes after you open it in the app.

1. Extract into a dedicated folder

Create a folder named Harmonicast alongside your existing library folders, outside your music folders. Extract the contents of the ZIP into it. Use Explorer, Finder, or your file manager for NAS and Windows/SMB shares.

Harmonicast/             ← library folder
  README.txt
  Harmonicast/           ← artist folder
    Shared Access Setup/
      01-setup.flac

The two Harmonicast folders are intentional. Point Plex at the outer one. If your extractor adds a folder named harmonicast-plex-setup, move its contents into the dedicated folder. Plex needs the extracted audio file, not the ZIP.

2. Make the folder visible to Plex

Docker and Unraid

If the parent media folder is already mapped, the new folder is visible through that mapping. If you map each library separately, add a mapping for the new folder.

Example with a mapped media parent:
Host:  /mnt/user/media/Harmonicast
Plex:  /media/Harmonicast

Example with a dedicated mapping:
Host:  /mnt/user/media/Harmonicast
Plex:  /harmonicast

Enter the Plex container path in the app. These are examples; use your own mapping.

Local disks, NAS, and Windows/SMB shares

For native Plex, use the full folder path accessible to its server process. A share opened as \\NAS\Media\Harmonicast on your computer may appear as /media/Harmonicast inside Plex. The app needs the path Plex sees.

The NAS does not need to run anything. The account Plex uses must be able to list the folders and read the audio file; your computer's access alone is not enough.

Permissions

Plex needs to list and traverse the folders and read the file. On Unix filesystems, 755 directories and a 644 audio file are suitable. Parent folders must allow access too. ZIP tools may ignore stored permissions.

For SMB or NAS storage, check share permissions and filesystem ACLs for the account Plex uses. No 777 permissions or recursive changes to your existing media are needed.

3. Finish in Harmonicast

Return to Settings → Music acquisition → Set up shared access. Enter the outer folder's path as Plex sees it, then choose Create setup library (or Use this folder).

After the scan finds Shared Access Setup, choose Prepare library. Harmonicast fills in and verifies the installation-specific, inactive record. You do not need to edit Plex's Summary/Review field.

Shared acquisition remains off. After Library ready, choose Connect dedicated account in Harmonicast to test and review publication. This ZIP contains no passwords, tokens, or server IDs.

Already set up, or something missing?

If you have a working Harmonicast Sharing Proof album from the test kit, keep it. Do not add this album alongside it: the setup library must contain only one setup album.

If Plex cannot find the album, check extraction, the folder mapping, and Plex's read permissions, then choose Scan for setup file. Restore a deleted audio file from the ZIP. If the inactive record was cleared, run setup again to review and restore it. Existing unrelated metadata is preserved.
